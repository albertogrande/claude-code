- Same release, cost visibility improves on two fronts: the **Stats panel now breaks out cache read/write tokens** in its totals, and auto mode's own permission-check classifier calls now **reuse the cached conversation prefix**, cutting the classifier's own prompt-cache cost — both land on the cost-control thread (models/context · feature · practice-candidate)
- [Dead Claude Code permission rules](https://gist.github.com/sfox100/128e8ef9f68109efe1322a56c5e67977) (HN, 1 pt but substantive) — audit of 149 public `.claude/settings.json` files finds Claude Code only matches path rules written as `Edit()`/`Read()`; rules written as `Write()`, `Glob()`, `NotebookEdit()`, or legacy `MultiEdit()` are silently accepted but never enforced. 16% of configs (21/134) had at least one dead rule, 50 dead rules total, 16 with no working equivalent — 8 of those targeting credential paths (`.ssh`, `.aws`, `.kube`, `*.pem`). Warnings for this only surface in interactive CLI sessions, not VS Code/CI/SDK. Worth a practice: audit your own `deny` rules for `Write()`/`Glob()` syntax (modes · tip · practice-candidate)
- [TokenMaxxer](https://tokenmaxxer.xyz) (Show HN, 5 pts) — a fourth local-transcript spend tool joins Gauge (08-03), `lnav` (08-01), and the manual audit (07-31): an opt-in-public leaderboard across 18 coding tools including Claude Code, reads local files only ("prompts and code never leave your machine, only the numbers you choose to share") (context · tip)
- [Claude gen-5 models show significant regression in BullshitBench](https://github.com/anthropics/claude-code/issues/83510) — reportedly, an open GH issue claims Sonnet 5/Opus 5/Fable 5 detect nonsense prompts far less often than 4.6/4.8 (0.52 vs 0.87 on the BullshitBench dataset) with ~2x verbosity at the same effort and Fable 5 allegedly silently rerouting to Opus 4.8 mid-session; methodology looks detailed (Wilson CIs, public dataset, scripts) but no official response or third-party replication yet — flagged, not confirmed (models · discussion)
