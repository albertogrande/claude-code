- [Dead Claude Code permission rules](https://gist.github.com/sfox100/128e8ef9f68109efe1322a56c5e67977) (HN, 1 pt but substantive) — audit of 149 public `.claude/settings.json` files finds Claude Code only matches path rules written as `Edit()`/`Read()`; rules written as `Write()`, `Glob()`, `NotebookEdit()`, or legacy `MultiEdit()` are silently accepted but never enforced. 16% of configs (21/134) had at least one dead rule, 50 dead rules total, 16 with no working equivalent — 8 of those targeting credential paths (`.ssh`, `.aws`, `.kube`, `*.pem`). Warnings for this only surface in interactive CLI sessions, not VS Code/CI/SDK. Worth a practice: audit your own `deny` rules for `Write()`/`Glob()` syntax (modes · tip · practice-candidate)
